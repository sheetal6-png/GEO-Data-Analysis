# GEO-Data-Analysis
End-to-end GEO dataset analysis including data preprocessing, differential gene expression, visualization, and functional enrichment analysis.

## Project Overview

This repository demonstrates a complete bioinformatics workflow for analyzing publicly available gene expression datasets from the NCBI Gene Expression Omnibus (GEO). The project includes downloading GEO datasets, preprocessing, differential gene expression analysis, visualization, and biological interpretation using R and Bioconductor.

## Objectives

- Download GEO datasets from NCBI
- Perform quality control and preprocessing
- Normalize expression data
- Identify Differentially Expressed Genes (DEGs)
- Generate publication-quality visualizations
- Perform Gene Ontology (GO) enrichment analysis
- Perform KEGG pathway enrichment analysis

---

## Workflow

1. Download GEO dataset
2. Data preprocessing
3. Data normalization
4. Differential expression analysis
5. Volcano plot
6. Heatmap
7. PCA analysis
8. GO enrichment
9. KEGG pathway analysis
10. Result interpretation
